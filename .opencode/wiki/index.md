- [[concepts/detail-pipeline]] — the four detail layers (10 cm lattice, base disks, hash-driven micros, LOD/shading) incl. the per-chunk `[base | edge bridges | material micros]` layout contract (`chunkRange <= edgeStart <= microStart <= chunkRange[i+1]`) and the live-edit micro path

- [[concepts/surfel-thin-rule]] — the thin-structure footprint rule (long lattice run + ≤3-cell cross-section → narrow ellipse) and its roof failure mode: a 2–3 cell cone/roof shell gets 5.5–7.5 cm disks that cannot seal staircase steps and renders as a sparse field of splats in the splat backend (SVO stays solid); author roofs as solid masses, plus the CPU run-rule diagnostic
- [[concepts/splat-base-seal]] — why the opaque base pass also stands in for everything the depth band rejects (so a translucent seal reveals the sky, not the background), and the measured frontier: the edge window buys nothing alone (1.00×) while the seal decline is the only thing that dissolves a silhouette (1.28×) and the only thing that costs interior fidelity (+5.6/255, 57% blue-dominant); the real fix is a coverage count in the already-allocated, still-unused D24_S8 stencil
- [[concepts/splat-edge-fade-measurement]] — how to measure a splat fragment change: establish the 0.18/255 same-binary noise floor first, never use `mean |splat−SVO|` as an interior metric (it is edge-dominated), require a bit-identical off-state control, and exclude the world-wide water plane from hole metrics
- [[concepts/edit-mode-hotkeys]] — the state-dependent keyboard: `Tab` is the ONLY View/Edit switch; `C`=Carve `A`=Add `D`=Delete `S`=Smooth `M`=Move pick a mode only while armed (in View mode they never switch the mode), `Ctrl+B` collapses the sidebar (it was `Tab`), `U` is micro-surfel detail; A/D/S stay camera keys in every state, plus the traps in the routing (every mode-key `edge()` latch must be read every frame, and mode switching must go through the one shared `chooseEditMode`)
- [[concepts/interactive-ui-coverage-gap]] — `drawHud()` is called only from `record_interactive.cpp`, so headless `--shot` renders omit the sidebar and hotkey bar entirely: no gate can catch a UI regression. The verification paths that do work (XTEST + `xwd`/`ffmpeg`, numeric masks over vision captions) and the actionable fix (`VF_TEST_PANEL=edit` calling `drawHud()` once)
- [[concepts/detail-normals]] — texture detail normals (render flag bit 7 / key B): a Sobel of the albedo luminance perturbs the shading normal; +40 % HF energy, shading-normal-only so SSAO/SSR are untouched
- [[concepts/texture-conformance]] — the drop-in gate for `assets/textures/`: tileable / albedo-only / no-stamp / on-palette, with `check_texture.py` + `prepare_texture.py` (strip → flatten → seamless). 1 of 13 AI candidates passed raw, 10 after repair
- [[concepts/texture-resolution]] — measured answer to "is resolution the biggest lever?": 256²→512² buys +4.8 % near-field HF energy for free, but relief and atmosphere move the same metric ~10× more
- [[concepts/water-caustics]] — the refracted-sun cell web and the absorption-alpha ceiling: the bed is 97 % hidden past 0.7 m, so caustics are composited at the surface (bed-only: 1.7 % of pixels at 10× strength; surface: 10.6 % at 0.85)
- [[concepts/world-detail-content]] — the 2026-09-19 shoreline reed layers (`hamlet_reeds`, `hamlet_reeds_far`): heightmap-driven placement, the saturated-green lesson, and the live_edit_check keep-out zone
- [[concepts/volumetric-fog]] — the J atmosphere rewrite: march to the G-buffer hit (not a fixed 16 m), correct forward-scatter sign, bounded extinction, sky-ambient + Mie sun lobe; the 42 %-darkening regression and its gate
- [[concepts/ssao-gbuffer]] — the normal G-buffer (`m_gnorm`) and the world-scale two-band SSAO: kernel, apply/denoise split, knobs, backend parity, `ssao_check`
- [[concepts/shading-model]] — the PBR lighting model (GGX, SDF AO, sky irradiance, aerial fog, grading) *(pre-splat-rework)*

- [[concepts/oriented-brush-rasterizer]] — rules for the axis-oriented brush stamps (Carve cylinder / Add growth): project the loop reach on `axisDir` (never world Y, or the brush no-ops on walls), make the profile branches meet at the switch plane instead of branching on a sign, and keep the CPU volume and the `BrushUBO` GPU preview as one shape; plus the 2026-10-03 **named falloff curves** (`Constant/Sphere/Root/Smooth/Linear/Sharp`) that replaced a scalar whose 0→0.001 cliff made it read as inert then confusing, the polarity rule for any exponent form, and why the panel prints the reach (the mark is genuinely smaller than Width), and the **2026-10-03 radial falloff** (`((1+cos(pi*q))/2)^k`) that gives Add/Carve proportional influence: polarity traps (a decreasing `k` inverts the control), the quadratic rim that avoids an fp knife edge, why only Carve's *far* end may taper, and why the Add dome's deliberate flat top was reversed on purpose
- [[concepts/live-edit-surfel-parity]] — a stamp re-derives the edit AABB ± margin, so the live/store surfel path must reuse the bake's normal pipeline verbatim (exposed-face mean → per-face expansion → neighbour smoothing). ## How to navigate
- Rendering: [[entities/svo-render]] (reference backend) + [[concepts/shading-model]]; the primary backend is the Gaussian-surfel rasterizer (`--mode splat`, default) — see `docs/rendering.md`. Screen-space effects + the normal G-buffer: [[concepts/ssao-gbuffer]]. Caves/interiors + authored lamps: [[concepts/enclosed-space-lighting]].
- Detail quality / tuning: [[concepts/detail-pipeline]] + [[concepts/edge-aware-surfel-radius]] + [[concepts/detail-normals]]; atmosphere: [[concepts/volumetric-fog]].
- Textures: [[concepts/texture-atlas]] (binding), [[concepts/texture-resolution]] (how much it buys), [[concepts/texture-conformance]] (the drop-in gate + repair tools).
- Live editing: [[entities/live-edit-brush]] (brush, per-voxel mode, click-vs-drag gate, undo/Clear, overlay) + [[concepts/oriented-brush-rasterizer]] (the axis-oriented stamp rules) + [[concepts/smooth-terrain-brush]] (terrain + object relaxation) + [[concepts/live-edit-surfel-parity]] (why the live/store surfel path must reuse the bake's normal rule verbatim); water: [[concepts/water-plane]].
- Why a brush size/depth change may not show up in the 3D view: [[concepts/brush-preview-visibility]] (the tint only marks existing surfels, so depth needs its own screen-space marker; the preview must survive sidebar hover; SVO now mirrors the preview).
- Before trusting a measurement, a "clean run", or a test-only fix: [[concepts/measurement-discipline]]; a worked example of an assertion whose instrument, not the code, was wrong: [[concepts/sky-probe-is-a-camera-assertion]].
- Sun / sky / day-night: [[concepts/sun-direction-pipeline]] (kSunDir production + every consumer, the reference-shot gate warning, and the loadSunManifest trap-and-fix).
- Asset integrity: [[concepts/overlay-silent-write-trap]] (VF_NO_OVERLAY is not a read-only guard — stamping renders still write assets/runtime_edits.vxw; the 2026-10-06 64MB→980KB loss) + [[concepts/uncommitted-edit-is-not-yours]] (a leading ` M` is not yours to restore).
- Caves / interiors / lamps: [[concepts/enclosed-space-lighting]] (bit-8 enclosure + the light UBO) + [[concepts/heightfield-blindness-enclosure]] (the two splat-path occlusion no-ops and why each was individually defensible).
- Editor/C++ completion, diagnostics, and build-dir coupling: [[concepts/clang-lsp-setup]]. Never `ninja -t clean` — see [[concepts/authored-assets-are-build-outputs]] (deletes the versioned scene) and [[concepts/clang-lsp-setup]] (also deletes the clangd database).
- Build/asset hazards: [[concepts/authored-assets-are-build-outputs]] (never `ninja -t clean`; restore from git before regenerating).
- App structure: [[entities/app-subsystems]]; sidebar UI: [[entities/hud-sidebar]].
- Suite/startup speed: [[concepts/load-time-field-build]]; test selection and the terrain-only live-edit coverage gap: [[concepts/focused-test-groups]].
- Verifying the GUI or live input (invisible to headless `--shot`): [[concepts/x11-input-injection]] + `tools/test_inject_iso.py`.
- Producing demo frames or stills: [[concepts/demo-capture]] + `tools/record_demo.py`; decision-driven live tours: [[concepts/decision-driven-navigation]] + `tools/vf_nav.py` (raise-before-capture, ASCII digest, tev1 at 0.1–0.7 s over direct HTTP).
- To add or edit world objects, follow [[concepts/voxel-object-authoring]] and the `voxel-object` skill.
- Full developer documentation: `docs/` (start at `docs/index.md`); engineering conventions for agents: `AGENTS.md`.
